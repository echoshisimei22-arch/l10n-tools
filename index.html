Word 文档翻译工具

本地提取 `.docx` 为可翻译 Markdown，并在翻译后回填到原始 Word，尽量保留表格、图片和样式。

使用说明
1. 上传 `.docx` 文件，点击“提取为 Markdown”。
2. 所有可翻译文本会以 ⟦T编号⟧ 的形式逐行输出，请在翻译时保留编号和每行结构，只替换编号后的文字。
3. 表格、图片、页眉页脚、脚注等内容不会被删除；生成译文时，工具只替换这些编号对应的文字。
4. 所有处理都在浏览器本地完成，不上传到服务器。
5. 建议使用 `.docx`，不支持旧版 `.doc`。
1上传原始 Word 文档
2原文 Markdown
可直接复制给翻译工具，也可以点击“下载 Markdown”保存为 `.md` 文件。
3粘贴译文 Markdown
如果某些行不需要翻译，也可以保留原文；工具会按编号回填。
